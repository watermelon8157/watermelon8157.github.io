# Repository Memory

## Stable Context
- **記憶架構**：本倉庫的長期記憶全部來源於 GitHub Issue 與 Comment，所有自動化整理皆以這些原始資料為根基。  
- **手動筆記**：`shared/manual.md` 內保留的手動筆記屬於 **穩定規則**、**長期決策**、**常見限制** 以及 **repo 習慣**，不會被自動流程覆寫。  
- **compact‑memory 工作流程**：  
  1. 只讀取 Issue/Comment，**不**完整複製原文。  
  2. 以摘要、關鍵詞或規則的形式蒸餾資訊，供後續 agents 共享與參考。  
  3. 手動筆記提供的「穩定規則」與「repo 習慣」會被所有 agents 共同遵守。  
- **目前狀態**：自 2026‑03‑29 起的每日快照皆顯示 **無可用 Issue**，因此沒有新增的跨 Issue 主題、決策或待辦。

## Recent Themes
- 最近 30 天內的每日快照均未偵測到任何跨 Issue 主題或重複出現的議題。  
- **結論**：目前沒有可供蒸餾為「近期主題」的資訊。

## Constraints
1. **資料來源限制**  
   - 只能從 GitHub Issue / Comment 取得原始資訊。  
   - 手動筆記僅作為輔助說明，不能取代 Issue 本身的內容。  
2. **內容重複規則**  
   - 不得在 `MEMORY.md` 中直接複製 Issue 原文。  
   - 必須以摘要或規則形式呈現，保持資訊的可讀性與可重用性。  
3. **更新頻率**
