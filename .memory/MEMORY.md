# Repository Memory

## Stable Context
- 本倉庫的長期記憶由 **shared/manual.md** 內的手動筆記維護，主要保存 **穩定規則、長期決策、常見限制** 以及 **agent 共同遵守的 repo 習慣**。  
- 目前 **沒有持續出現的 Issue、跨 Issue 主題或已確定的決策**，因此在穩定上下文中暫無可列舉的具體規則。  
- 既有的工作流程假設 **GitHub Issue / Comment 為唯一原始資料來源**，手動筆記僅作為摘要與指引，不會被自動覆寫。  

> **不確定性**：因為最近 30 天的每日快照皆未檢測到可用 Issue，無法從實際執行紀錄中抽取更多穩定規則或慣例。

## Recent Themes
- **無可辨識的跨 Issue 主題**：過去 30 天的每日快照均顯示「目前沒有可辨識的跨 issue 主題」。  
- **無新決策**：每日快照皆報告「目前沒有新的跨 issue 決策」。  

> 若未來出現持續出現的議題或決策，請於此節更新。

## Constraints
1. **資料來源限制**  
   - 只能以 **GitHub Issue / Comment** 為原始資訊來源，其他來源（如聊天記錄、外部文件）不列入自動記憶建構。  
2. **手動筆記原則**  
   - `shared/manual.md` 只作為 **長期記憶的手動維護**，不應直接複製完整 Issue 內容。  
   - 任何自動化流程（如 compact‑memory workflow）會 **讀取** 但 **不會覆寫** 此檔案。  
3. **Issue 數量與時間範圍**  
   - 每次快照限制為 **最近 30 天、最多 100 個 Issue**，若超出此範圍則不會被納入當前記憶。  

## Open Loops
- **等待 Issue 更新**：目前所有每日快照皆顯示「等待下一輪 issue 更新後再整理」，代表缺乏可供整理的 Issue。  
- **未確定的長期規則**：因缺乏實際案例，尚未形成可寫入 **Stable Context** 的具體規則。
